# «Связь поколений: мы помним»

Интерактивный сайт для конкурса в номинации **«Связь поколений: мы помним»** (возрастная группа 14–21 год).
Проект посвящён сохранению исторической памяти о событиях Великой Отечественной войны, героическом
прошлом белорусского народа, преемственности традиций и диалогу поколений.

## Разделы сайта

- **Главный экран** — Брестская крепость, призыв к действию
- **О проекте** — почему важно помнить, анимированные факты-цифры
- **Хроника** — лента ключевых событий войны в Беларуси (1941–1945): каждое событие — карточка с фоновым фото и градиентом для читаемости текста
- **Герои** — 16 героев: 10 женщин (2026 год в Беларуси — Год женщины) и 6 мужчин:
  Вера Хоружая, Зина Портнова, Елена Мазаник, Мария Осипова, Надежда Троян, Татьяна Мариненко,
  Елена Колесова, Зинаида Туснолобова-Марченко, Маша Брускина, Римма Шершнёва,
  Пётр Гаврилов, Константин Заслонов, Пётр Машеров, Марат Казей, Иван Якубовский, Николай Гастелло
- **Места памяти** — галерея мемориалов: клик по карточке раскрывает полную историю («Читать далее»), клик по фотографии открывает её крупнее в лайтбоксе. Мемориалы: Брестская крепость, Хатынь, Курган Славы, Монумент Победы, Линия Сталина, Тростенец
- **Свеча памяти** — единственная свеча: с одного устройства её можно зажечь только один раз. При запуске через `node server.js` сервер отличает устройства по уникальному токену — поэтому даже за одним IP (школьная сеть, домашний Wi-Fi) каждый получит свою свечу. Защита от ботов — не более 50 свечей с одного адреса (настраивается переменной `CANDLES_PER_IP`). Без сервера свеча сохраняется в браузере устройства
- **Диалог поколений** — как молодёжь хранит память (поисковые отряды, волонтёры, музеи, встречи)
- **Бессмертный полк нашей памяти** — посетители подают заявки о своих родственниках-ветеранах
  (имя, годы жизни, звание, место, рассказ; фото — по желанию). Каждая заявка проходит **модерацию**
  через админ-панель `admin.html`, после одобрения ветеран попадает в общий полк (счётчик «В полку»,
  поиск по фамилии). Без сервера полк показывает примеры, а форма сообщает, что нужен `server.js`
- **Викторина** — 15 вопросов с объяснениями и итоговым результатом (порядок вопросов и ответов перемешивается при каждом прохождении)

## Технологии

Чистые HTML + CSS + JavaScript, без внешних зависимостей и сборки. Для работы
не нужен сервер — достаточно открыть `index.html` в браузере.

Для счётчика свечей и «Бессмертного полка» приложен простой сервер на Node.js
(`server.js`, без внешних библиотек). Он раздаёт сайт и ведёт учёт «свеча на
устройство»: каждое устройство запоминается уникальным токеном, поэтому
несколько человек за одним IP-адресом получают каждый свою свечу
(защита от ботов — до 50 свечей с одного адреса). Данные — в `data/candles.json`.

Там же живёт «Бессмертный полк»: заявки посетителей с фото и рассказом
сохраняются в `data/regiment.json` со статусом `pending` и ждут модерации.
Админ-панель (`admin.html`) входит по паролю, показывает очередь и позволяет
одобрить (с редактированием текста), отклонить или удалить заявку.
Пароль по умолчанию — `admin2026` (задаётся через `ADMIN_PASSWORD=... node server.js`).

## Как открыть

**Вариант 1 — просто посмотреть (без сервера):** двойной щелчок по
`index.html`. Всё работает, но счётчик свечей хранится только в браузере.

**Вариант 2 — полный (свечи по устройствам + модерация полка):** запустите из папки проекта:
`node server.js` и откройте `http://127.0.0.1:8123/` (порт можно указать
своим: `node server.js 3000`).

**Админ-панель модерации:** `http://127.0.0.1:8123/admin.html`, пароль по умолчанию `admin2026`
(можно задать свой: `ADMIN_PASSWORD=мойпароль node server.js`). Для демонстрации очереди
можно открыть сайт в нескольких вкладках/устройствах, подать заявки и одобрить их в админке.
Чтобы очистить данные полка, удалите файл `data/regiment.json`.

Единственный внешний ресурс — шрифты Google Fonts (при отсутствии интернета сайт отображается
системными шрифтами).

## Публикация на бесплатном хостинге (полная версия)

Проект рассчитан на хостинг, который умеет выполнять Node.js, — тогда работают и модерация
«Бессмертного полка», и учёт свечей по устройствам. Бесплатный вариант — **Render** (не нужна
банковская карта). Порядок:

1. Создайте репозиторий на GitHub (можно приватный) и загрузите в него папку проекта.
2. Зарегистрируйтесь на https://render.com (через GitHub) и нажмите **New → Web Service**.
3. Подключите репозиторий; Render сам определит Node.js. Команды можно не менять
   (`build` не требуется, `start` = `node server.js` из `package.json`).
4. В разделе **Environment** при желании задайте свой пароль админки:
   `ADMIN_PASSWORD` (по умолчанию — `admin2026`).
5. **Deploy**. Через пару минут сайт будет доступен по адресу вида
   `https://ваш-проект.onrender.com`, админ-панель — `https://ваш-проект.onrender.com/admin.html`
   (вход только по паролю; без него данные модерации недоступны).

**Особенности бесплатного тарифа Render:**
- сервис «засыпает» через 15 минут без посетителей и просыпается ~через минуту по первому запросу
  (для демонстрации просто откройте ссылку заранее);
- файлы данных (`data/candles.json`, `data/regiment.json`) лежат на временном диске и
  **сбрасываются при перезапуске или редеплое** — подавайте заявки в полк перед показом жюри,
  либо разверните свежие данные после деплоя.

Альтернативы: **Koyeb** (бесплатный Node-сервис не засыпает, но нужна карта и доступен
только регион Франкфурт/Вашингтон), **Northflank** (2 бесплатных сервиса, всегда включены,
в комплекте бесплатная база данных — но её подключение потребует доработки кода).

**Статический режим (без сервера):** если нужен только сайт без модерации, подойдёт любой
статический хостинг — Cloudflare Pages (безлимитный трафик, 500 деплоев/мес) или Netlify
(загрузка папки перетаскиванием). В этом случае свеча сохраняется в браузере, а полк
показывает примеры (админка без сервера не работает).

## Структура

```
svyaz-pokoleniy/
├── index.html      — разметка
├── admin.html      — админ-панель модерации «Бессмертного полка»
├── css/style.css   — оформление
├── js/main.js      — интерактив
├── server.js       — необязательный сервер: раздача + свечи по устройствам + модерация полка
├── package.json    — описание проекта и команда start (для облачного хостинга)
├── data/           — создаётся сервером: candles.json (свечи), regiment.json (полк)
├── img/            — фотографии мемориалов
└── README.md
```

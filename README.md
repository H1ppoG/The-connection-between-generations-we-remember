# Связь поколений: мы помним

Интерактивный сайт для конкурса в номинации **«Связь поколений: мы помним»** (возрастная группа 14–21 год).
Посвящён сохранению памяти о Великой Отечественной войне, героическому прошлому белорусского народа
и диалогу поколений.

Две языковые версии: **русский** и **белорусский**, переключение в шапке, выбор сохраняется в браузере.

## Разделы

- **Главный экран** — Брестская крепость, призыв к действию
- **Свеча памяти** — зажечь виртуальную свечу в память о героях. С одного устройства свеча зажигается
  один раз: сервер различает устройства по уникальному токену, поэтому за одним IP (школьная сеть,
  домашний Wi-Fi) каждый получает свою свечу. Ограничение для ботов — до 50 свечей с одного адреса
  (`CANDLES_PER_IP`)
- **О проекте** — почему важно помнить, факты-цифры с анимацией счётчиков, цитата Рождественского
- **Хроника** — ключевые события войны на территории Беларуси (1941–1945). Фотография и текст
  расположены по разные стороны центральной линии, чередование сторон
- **Герои** — 16 героев: 10 женщин (2026 год в Беларуси — Год женщины) и 6 мужчин. Клик по портрету
  открывает карточку с годами жизни, биографией и списком подвигов; стрелками и клавишами ← → можно
  переключаться между героями
- **Места памяти** — галерея мемориалов: клик по карточке раскрывает историю, клик по фотографии
  открывает её крупнее с навигацией стрелками
- **Диалог поколений** — как молодёжь хранит память: поисковые отряды, волонтёры, музеи, встречи
- **Бессмертный полк нашей памяти** — посетители подают заявки о своих родственниках-ветеранах
  (имя, годы жизни, звание, место, рассказ, фото по желанию). Заявка проходит модерацию через
  `admin.html`, после одобрения ветеран попадает в общий полк со счётчиком и поиском по фамилии
- **Викторина** — 15 вопросов с пояснениями и итогом. Порядок вопросов и ответов перемешивается
  при каждом прохождении

## Технологии

Чистые HTML, CSS и JavaScript. Нет сборки и внешних зависимостей. Сайт работает, если просто открыть
`index.html` в браузере.

Для счётчика свечей и «Бессмертного полка» есть сервер на Node.js без внешних библиотек:

- раздаёт статические файлы;
- ведёт учёт «одна свеча на устройство» по токену;
- принимает и хранит заявки полка в статусе `pending`;
- отдаёт API для модерации.

Админ-панель входит по паролю, показывает очередь заявок и позволяет одобрить (с правкой текста),
отклонить или удалить заявку.

## Запуск локально

**Посмотреть без сервера:** открыть `index.html`. Всё работает, счётчик свечей хранится в браузере.

**Полный режим** — из папки проекта:

```
node server.js
```

Сайт: `http://127.0.0.1:8123/`, админка: `http://127.0.0.1:8123/admin.html`.
Порт задаётся аргументом (`node server.js 3000`), пароль админки — переменной окружения
(`ADMIN_PASSWORD=мойпароль node server.js`), по умолчанию `admin2026`.

Данные лежат в `data/`: `candles.json` (свечи) и `regiment.json` (заявки полка). Чтобы очистить
очередь полка, достаточно удалить `data/regiment.json`.

Единственный внешний ресурс — шрифты Google Fonts; без интернета подставятся системные шрифты.


## Структура

```
svyaz-pokoleniy/
├── index.html            — разметка сайта
├── admin.html            — админ-панель модерации «Бессмертного полка»
├── css/style.css         — оформление
├── js/i18n.js            — словари переводов ru / be, переключение языка
├── js/main.js            — интерактив
├── server.js             — раздача сайта, свечи, приём и модерация заявок
├── package.json          — описание проекта и команда start
├── data/                 — создаётся сервером: candles.json, regiment.json
├── img/                  — фотографии мемориалов
└── img/heroes/           — портреты героев
```
